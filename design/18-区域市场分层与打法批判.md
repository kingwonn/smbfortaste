# 18-区域市场分层与打法批判

**这篇解决什么问题:** 方案持有者要求说明白:大城市和小城市、东部和西部、及其四种组合,市场和产品及打法的区别与异同,并做针对性批判分析。本篇先立机制框架(地理标签不是变量,五个机制变量才是),再按两条轴拆开,给四象限打法,最后一节**对本项目自己既有假设的批判**——包括 docs/09"北方县域"这个立足点本身。所有密度与金额数字沿用 docs/09/design/12 口径,均为(估),推进任何一个新象限前必须实地重验。

## 一、先立框架:别用地理想问题,用五个机制变量想

"大城市/小城市、东部/西部"是行政地理标签,不是生意变量。真正决定这门生意(给小饭店赊销配送的个体户 + 武装他们的工具)在一地成不成立的,是五个机制变量:

| 机制变量 | 它决定什么 | 大→小城市怎么变 | 东→西怎么变 |
|---|---|---|---|
| **V1 客群结构**(夫妻店餐馆 vs 连锁化) | 有没有"赊销人情账"这个需求本体 | 连锁化率降,夫妻店占比升 | 变化不大(弱) |
| **V2 供给形态**(配送商是夫妻店还是公司) | 我们的"单人心智"产品对不对得上人 | 大城市配送商公司化、雇人、分工 | 变化不大(弱) |
| **V3 平台压强**(快驴类覆盖强度) | 结构真空存不存在 | 一二线强、县域≈0(快驴2021实证) | 东部强于西部(估) |
| **V4 密度与半径**(目标店数/城、配送半径) | 地推模型和单城 TAM 成不成立 | 地级市30~80家、县城5~20家(估) | **西部密度显著更低、半径更大(估)** |
| **V5 触达与语料**(渠道渗透、口音说法) | 获客渠道和拆单器/语音转写的命中率 | 变化不大 | **快手北强、口音与品类说法变化大** |

**先把结论的骨架亮出来:城市层级是强轴(V1/V2/V3 全被它驱动),东西部是弱轴(主要动 V4/V5)。**"东部大城市 vs 西部大城市"对我们的差别,远小于"任何一地的大城市 vs 县城"。谁把东西部当主要矛盾,谁就在用宏观叙事代替生意分析——这是本篇第一个批判对象(包括提问方式本身)。

## 二、强轴:大城市 vs 小城市

### 市场端的区别

| | 大城市(一二线) | 小城市(县城/三四线) |
|---|---|---|
| 餐饮客群 | 连锁化率高,中央厨房/供应链公司介入;夫妻店集中在城中村/城乡结合部 | 街边夫妻店餐馆为主体,连锁少 |
| 结算文化 | 现结/平台账期为主,快驴类聚焦于此(design/12) | **赊销月结+人情信用是主流** |
| 配送商形态 | 公司化:雇人、多车、分品类批发商分层(一批/二批) | 夫妻店个体户:老板跑市场、老板娘管账 |
| 平台压强 | 强:快驴明确聚焦一二线现结(2021实证) | ≈0:快驴撤、美菜清退500县、有菜关停 |
| 同行密度 | 高,但被平台和大商挤压 | 5~20家/县、30~80家/地级市(估) |
| 他们的头号痛点 | 获客、账期资金、与平台抢客户 | **账糊涂、赊账收不回**(我们打的正是这个) |

### 产品端的区别——这条最狠

我们的产品到今天为止的全部设计,赌的是一个人:**老板娘,一个人,晚上,把全店的账管完**(design/17 四条铁律、单人心智、听汇报)。这个假设在县城成立,在大城市配送商那里**碎掉**:公司化配送商要的是员工账号、权限、多车排线、司机与库管分工、防止伙计吃回扣——那是另一个产品形态(多人协作层),我们只在 M2+ 远期清单里。**拿家用版去大城市,不是市场不接受,是产品对不上人。**

### 结论

小城市是主场,不是退而求其次,是结构选择:平台亏钱验证过的真空(design/12)+ 产品与用户一对一咬合。大城市现在不去,去了也打不着——他们的痛点(获客/资金)我们一条都不解,而我们解的痛点(赊销人情账)在现结市场里不存在。

## 三、弱轴:东部 vs 西部——只改四件事,但每件都要认真改

东西部不改变生意的性质(县域夫妻店餐馆+赊销配送的结构全国同构),但改四个参数:

1. **密度与半径(V4,最实质)**:东部县域(苏鲁豫皖冀)人口密、县城大、餐饮网点多,一个县 5~20 家同行的估算靠东部这头;西部县域地广人稀,可能一县 2~5 家(估)、配送半径翻倍。**直接后果:docs/09 的"一城一市场,地推复制"模型在西部失效**——跑一趟的获客产出可能不够路费。
2. **付费承受力**:docs/09 的 300~1000 元/年无痛区间按北方县域标定;东部百强县同行的心理账户可能更高(估),西部则连 365 也要多磨几句。但**不按地域分价**——"一天一块钱"这句话术的全国一致性,比每城多收一两百重要(docs/09 定价原则的延伸)。
3. **语料与口音(V5,产品真影响)**:拆单器的省略语("一件醋""老样子来一套")、单位习惯、品类叫法(同一样菜南北各叫各的)、语音转写的口音命中率——全部按妹妹店(北方)的真实语料打靶。**90% 准确率是本地过拟合**,这在本店是优点(design/06),复制到新地域必须按 design/03 五步重新打靶,西部口音区、方言区尤甚。
4. **渠道**:快手在北方县域渗透最高(design/12 已定为首选阵地),南方与西南抖音相对更强(估)——获客内容一样拍,投放阵地按地域换。

## 四、四象限组合打法

| 象限 | 判断 | 打法 |
|---|---|---|
| **东部小城市** | **第一曲线,主战场** | 现行方案原样:妹妹店样板 → 本市批发市场地推 → 邻城复制。密度撑得起"一城一市场",同行多到口碑能传染 |
| **西部大城市**(成渝西安兰州这类区域枢纽) | **第二曲线候选,唯一值得多看一眼的大城市** | 理由:平台压强低于东部一线(估)、餐饮密度高、**枢纽批发市场辐射周边县域**——在枢纽市场发展一个代理/样板,等于间接触达它辐射的几十个县(docs/09 模式3的正确落点)。但仍要先解决 V2:枢纽大商已公司化,需要多人协作层,故排 M2 后 |
| **东部大城市** | **最后进,或不进** | 平台主场+公司化配送商,双重错位。唯一 niche:城中村/城乡结合部的小配送户(结构上是"嵌在大城市里的县城"),但获客要一个村一个村跑,密度优势荡然无存。不值得主动投入,有自然单就接 |
| **西部小城市** | **不主动进,被动接** | 需求最真(人情赊销最强)但单城 TAM 最小,地推账算不平。打法:不去。靠快手内容的自然流量转化,来一家服务一家,把它当零成本长尾,不当市场 |

**顺序压成一句:先东部小城市打透,西部大城市当第二曲线储备,两个"错位象限"(东部大城市、西部小城市)一个不追、一个只接。**

## 五、产品含义:什么全国不变,什么按地换

**不变(地理不变量,恰是产品核心)**:账务内核(整数分、流水、核销、账龄)、四条铁律、回执留证、赊销对账、微信语音收单——全国的小饭店老板都在微信里说"明天照旧"。**这层一行代码不用改,这正是它该是核心的证明。**

**要换(全部走配置,不动内核)**:拆单语料与常用品对照表、品类目录与单位习惯、价格模式配比(design/03 的六维配置机制天然承接——**地域适配就是行业模板机制的孪生**,不需要新发明);语音转写引擎的口音适配;获客渠道(快手/抖音)按地选。**新增一条纪律:每进一个新地域,同新行业一样,先找一家样板店免费共创、语料重新打靶,打不到 90% 不收这个地域第二家的钱**(design/03 五步流程原样适用于地域)。

## 六、针对性批判:对我们自己既有假设开炮

1. **"北方县域"是初始条件,不是市场论证——要说破。** docs/09 通篇以"北方"为市场边界,真实原因是妹妹的店在北方、样板与语料都长在北方。这个起点**正确**(样板店逻辑,design/13),但文档把它写得像市场选择的结果,是用结论包装了条件。诚实的说法:南方非强方言区县域(如两湖、江西、皖南)从未被论证排除,它们的 V1~V4 与北方县域近似,差的只是 V5 语料——按第五节纪律进入即可。北方 1~3 万家的 TAM 口径(估)因此是**下限**不是边界。
2. **"一城一市场地推"隐含东部密度,西部会亏在路上。** docs/09 第六节的地推模型没标注它的密度前提。本篇补上:该模型仅在 V4≥东部县域水平时成立,西部按四象限降级为被动接单。
3. **拆单准确率是本地过拟合,别拿着 90% 去新地域吹。** design/06 的"≥90% 且错归=0"是本店语料的成绩。地域一换,省略语和品类叫法全变,准确率会先掉再爬。产品早有对策(拿不准标红,绝不猜——错单不出门,掉的只是自动化率不是正确性),但**推广话术里不许承诺准确率,只承诺"错单过不了确认这道门"**。
4. **防"大城市诱惑"。** 密度高、店多、客单大,看着像好市场——那是快驴的主场,人家亏了 69 亿(2025 年报,design/12)换来的教训替我们踩过了。我们的结构优势(赊销人情账数字化)在现结市场归零,进大城市等于自弃兵器。任何"大城市单店客单更高"的算术都要先过 V2/V3 这两关。
5. **警惕本篇自己的框架。** "东西部"其实是**批发市场形态**的代理变量:真正的分层是"县域农贸市场(单一、熟人)vs 枢纽批发市场(分层、公司化)"。行政地理只是它的影子——所以成都(西部)归"枢纽",苏北县城(东部)归"县域"。执行时按市场形态判断,不按省份地图判断;本篇用东西部行文,是迁就提问框架,不是认可它。
6. **所有密度/付费力数字都是(估),且比 docs/09 的估更软。** docs/09 的估算至少有本店所在市可验;本篇关于西部密度、南方渠道偏好、枢纽辐射力的说法连一手观察都没有。**每条都是待验假设,不是依据。**

## 七、落地:现在一件事都不用多做,顺手记三样

家用版先行、本店数据说话的路线(design/13)不因本篇改一个字。只在既有动作里顺手加三样零成本的事:

1. **地推时录"说法差异"**:本市地推(docs/09 第二步)每聊一家同行,顺手记他口里跟妹妹店不一样的叫法/单位/规矩——这是未来地域模板的第一批语料,白捡;
2. **快手自然流量当免费探测器**:样板店短视频发出去后,看哪些地域的同行来私信——观众的地理分布就是零成本的市场热力图,好过任何拍脑袋的东西部判断;
3. **给"枢纽假说"留个钩子**:若有成渝西安的同行自然找上门,升级为重点访谈对象(远程即可),验证第四节西部大城市象限的判断——在花一分钱去西部之前。
