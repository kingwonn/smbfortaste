# 10-实现选型与CF架构

**这篇解决什么问题:** 方案持有者定了两条实现原则——**参考 SOTA 项目、不重复发明轮子;后端控制面放在 CF(Cloudflare)上**。本篇给出轮子清单、CF 架构、对 design/02 技术选型的修订,以及必须说透的大陆访问与备案注记。已落地代码见 `app/`。(若"CF"实指"云函数",design/02 阶段A 的云开发方案保留为 B 计划,一句话即可切换。)

## 一、为什么 CF 这步棋走得对

D1 是真 SQLite:**唯一约束、条件更新、按语句原子都是原生的**——原设计里最难的两件事(取号防重、幂等)难度直接砍半;Cron Triggers 天然承接夜间重算校验与结算单定时生成;R2 存回执照片没有出口流量费。更重要的一条:**Workers 从 1 家租户到 1000 家是同一套栈,design/02 的"阶段A云开发→阶段B自建"迁移整个消失**——技术评审【严重#八】"迁移承诺低估一个量级"整条批评作废,这是架构上最大的一笔减负。

## 二、轮子清单(不重复发明)

| 轮子 | 用在哪 | 说明 |
|---|---|---|
| **Hono** | Workers 路由/中间件 | Workers 生态事实标准,已落地 `app/server/src/index.js` |
| **D1**(SQLite) | 主库 | JSON data 列+生成列落索引的文档式建模,schema 见 `app/server/schema.sql` |
| **R2** | 回执照片 | 免出口流量费;photo 存相对 key,兑现 design/02 存储抽象承诺 |
| **Cron Triggers** | 夜间重算校验(03:00)/结算单生成 | 已在 `wrangler.toml` 配置 |
| **Queues** | 结算单分片扇出(租户多时) | 付费计划才有,M2 再启用,当前 Cron 内循环即可 |
| **KV** | 会话/客户档案缓存 | M1 按需 |
| **Workers AI(Whisper)** | 复述音频转写候选 | 与微信同声传译插件并列评估(M2) |
| **wrangler + miniflare** | 本地开发/部署 | 本仓库另备 node:sqlite 版 D1 模拟器,`node --test` 零依赖跑全套 |
| **TDesign 小程序组件库** | 小程序 UI | 腾讯官方,大字模式基线自定;备选 Vant Weapp |
| **Vue3 + Vite + TDesign** | PC 工作台(M2) | 与小程序同一设计语言 |
| **Drizzle ORM** | 可选演进 | 当前"JSON+生成列"模式够用;查询变复杂再引入,不提前上 |
| 开源进销存(如 jshERP 类) | 领域参考 | 只参考单据/科目/库存模型的划分,不引代码——我们的差异化恰在"不做通用进销存" |

## 三、架构(修订 design/02 第一、二章)

```mermaid
flowchart TB
    subgraph WXS["微信侧(不变)"]
        MP["小程序(老板/老板娘/配送员)"]
        CU["客户微信(零安装卡片+账本页)"]
    end
    subgraph CF["Cloudflare(后端控制面)"]
        W["Workers + Hono<br/>鉴权/租户注入/参数校验"]
        CORE["app/core 账务内核<br/>(平台无关,同一包)"]
        D1[("D1 主库<br/>schema.sql")]
        R2[("R2 回执照片")]
        CRON["Cron 03:00 夜间重算<br/>+ 结算单定时生成"]
    end
    MP -->|HTTPS(备案域名)| W
    CU -->|卡片落地页| MP
    W --> CORE --> D1
    W --> R2
    CRON --> CORE
    W -.code2session/订阅消息.-> WXAPI["微信开放接口"]
```

分层纪律(已在代码里执行):**Workers 层只做鉴权、租户注入、校验、存储适配;业务逻辑全部在 `app/core`**——内核 28 个测试 + 服务层 2 个端到端测试,内存/D1 双存储同套行为。

## 四、必须说透的三条注记(不许被热情掩盖)

1. **小程序 request 合法域名必须 ICP 备案。** 买域名+备案是硬前置(数周),本周就该启动;备案期间用 `wrangler dev`+开发者工具白名单豁免开发,不堵进度。支付回调域名同理。
2. **大陆访问 Cloudflare(无中国网络)时延约 100~300ms、偶发抖动。** 本产品全是低频操作(开单/拍照/记款),可接受——但要实测,不要信感觉:**M0 新增打靶⑦:县城真机对 Workers 连续 3 天测 RTT/失败率**(判据示例:P95<800ms、失败率<1%)。不达标的 B 计划:同一套 `app/core` 迁国内运行时(Node 自建或国内边缘),内核零改动——这正是内核平台无关的价值。
3. **微信 API 从海外 IP 调用可行**(code2session/订阅消息不限调用方地域),但接口频控与 IP 白名单要在 M0 一并验证。

## 五、成本(示例,以官网实时价为准)

Workers 付费计划 $5/月 + D1/R2 免费额度(本产品量级内基本免费)≈ **全栈月成本 0~40 元人民币**,低于原云开发方案;域名+备案一次性约百元级。对照 docs/09 定价,毛利结构进一步改善。
