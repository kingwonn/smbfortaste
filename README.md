# 中山店铺 · 调味品配送生意完整管理方案(SMB for Taste)

一套写给**北方三线及以下城市(地级市/县城)调味品/粮油批发配送门店**的完整管理方案:从客户微信语音下单,到清晨农贸批发市场集中采购,到按路线配送、三联回执签收,再到月末对账收款——全流程的制度、单据、账本和数字化路线,拿来就能用。

**客户是谁**:小饭店/面馆/烧烤店、大学食堂档口、中大型酒店后厨、单位食堂。
**方案给谁看**:没上过管理课、每天很忙的小老板。全部文档口语化,每篇结尾附"本周就能做"的落地清单。

## 核心流程(一天的节奏)

```mermaid
flowchart LR
    A[客户微信语音/文字/电话下单] --> B[转录成标准订单<br>文字复述确认]
    B --> C[清晨汇总订单<br>生成采购汇总单]
    C --> D[农贸批发市场集中采购<br>验货索票]
    D --> E[分拣装车<br>按路线配送]
    E --> F[三联送货回执单签收]
    F --> G[下午回收回执<br>登记销售账/应收账]
    G --> H[月末对账单<br>收款销账]
```

**方案的灵魂是三联送货回执单**:对门店,它是签收凭证和收钱依据;对饭店老板,它是管理员工的工具——员工代收货时单上品名数量单价写得清清楚楚,老板凭它核对进货、防虚报吃回扣。帮客户管店,就是留住客户。

## 快速上手(三步)

1. **今天**:按《02-订单管理》立"复述确认"规矩——客户每条语音订单,回一条格式化文字确认。
2. **本周**:去打印店用 `templates/print/送货回执单.html` 版式印三联回执单,开始张张签收;按《01》给客户微信备注改名分级。
3. **本月**:启用 `tools/管理账本.xlsx`,月底出第一份对账单;通读《05-财务与对账》,给每个赊账客户划信用红线。

## 设计原则

1. **口头生意落成白纸黑字**:每一单有登记、有回执、有对账,凭据说话。
2. **回执单双重价值**:既是门店的收款凭据,也是饭店老板管员工的工具。
3. **交互极简**(见《10》):语音或简单点击即可完成,超过 3 步的操作等于没做;对账等算账的活儿全部自动,人只做确认和例外处理。

## 关于通用化推广(见《09》详细评估)

结论一句话:**流程与工具层通用性强,值得做成标准化产品;资源层(供应商/路线/客情)不可复制也无需复制。** 北方目标门店粗估 1万~3万家量级(估算),建议"先卖咨询包验证付费意愿 → 再做轻量小程序按年订阅 → 联盟模式看情况"三步走,定价压在县域小老板无痛区间(示例:基础版 365 元/年,"一天一块钱");所有推广话术落在"少丢钱、早收钱",不讲"数字化转型"。
