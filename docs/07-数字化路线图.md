# 07-数字化路线图

**这篇解决什么问题:** 不懂电脑的小老板,怎么一步一步从纸质账升级到数字化——第1个月一分钱不花,第2-3个月用一个Excel账本,第4-6个月再考虑花几百块上正经软件。每一步什么时候该迈、什么信号说明该升级了,这篇都写清楚,保证不花冤枉钱。

## 一、先把话说明白:数字化不是买软件,是先立规矩

很多老板一听"数字化"就以为要买电脑、买软件、招个会电脑的人。错了。咱这生意的数字化,顺序是反过来的:

> **先把规矩立好(单据、流程、字段统一)→ 再把纸上的东西搬进Excel → 最后才是买软件。**

软件只是把你已经在做的事变快,它替代不了规矩。规矩乱着就上软件,等于把一团乱麻塞进机器,越搅越乱,最后骂一句"软件不好用",钱白花。所以路线图分三个阶段,一个台阶一个台阶上,每一阶段站稳了再上下一阶。

三个阶段一览(费用均为示例):

| 阶段 | 时间 | 花多少钱 | 干什么 |
|---|---|---|---|
| 阶段一 | 第1个月 | 0元(印单据一两百元) | 微信规范化+纸质单据跑通全流程 |
| 阶段二 | 第2-3个月 | 近0元 | 启用 tools/管理账本.xlsx,每天下午录单30分钟 |
| 阶段三 | 第4-6个月 | 每年几百到一两千元 | 选一款轻量进销存App,导入历史数据 |

## 二、阶段一(第1个月,0成本):微信规范化+纸质单据

这一步不碰电脑,只干两件事:把微信理顺、把纸质单据用起来。别小看它——**这一个月练的就是"字段统一、单单有号、张张有签字"的习惯**,后面两个阶段全靠它打底。

### 1. 微信规范化

- **好友备注统一格式**:「级别-店名-老板称呼」,如"A-向阳大酒店-刘经理""C-老王面馆-王哥",再打上路线、类型标签。详细规矩见《01-业务模式与客户管理》。
- **订单复述确认**:客户微信语音、电话下单,门店立刻转成文字标准订单(品名/规格/数量/单价),原样复述发回微信让客户回个"对"。这条微信就是最原始的电子凭证,别删。示例对话见《02-订单管理》。
- **一天一搜就能查**:备注规范了,月底想查"老王面馆"全月订单,微信搜店名就全出来了——这已经是最土但最管用的"数据库"。

### 2. 纸质单据全套跑起来

- 去街上打印店,按 templates/print/ 里的版式印**三联无碳复写送货回执单**(一次写、三联同字),先印20本(示例:一两百元);印法和用法见《04-配送与回执》。
- **纸质订货登记表**打印或抄一个本子,接一单记一单,单号按 DD+年月日+2位序号编;回执单号按 HZ+年月日+2位序号。
- 采购汇总单、装车配送单也照 templates/ 目录里的模板用纸质版,字段一个都别改——这些字段就是阶段二Excel里的表头,现在写顺手了,以后录电脑就是照抄。

### 3. 阶段一的合格线

月底自查:①每天的订单都有订单号、都复述确认过;②每张送出去的货都有签了字的回执单;③晚上日结能对上钱。三条都做到,才有资格进阶段二。

## 三、阶段二(第2-3个月,近0成本):用上"管理账本.xlsx"

纸质账的毛病是**不会算**:月底给A类客户出对账单,得把一沓回执单一张张翻、拿计算器加;想知道"这个月豆瓣酱卖了多少",没法查。Excel就是来解决"算"和"查"的。

### 1. 账本长什么样

本仓库 tools/管理账本.xlsx 就是给咱定制的,各个sheet(工作表)的用途:

| Sheet | 干什么用 | 对应纸质单据 |
|---|---|---|
| 使用说明 | 第一次用先读这页 | — |
| 商品目录 | 所有在售商品的品名/规格/单位/参考进价售价,录单时照着选,名字不会写乱 | 见《06-库存与商品管理》 |
| 客户档案 | 一户一行:编号、店名、分级、结算方式、代收货人等 | 客户档案卡 |
| 订单登记 | 每天的订单流水 | 订货登记表 |
| 采购记录 | 每天市场采购的实际花销 | 采购汇总单 |
| 送货回执登记 | 每张回执单录一行:单号、客户、金额、是否已收款 | 回执单对账联 |
| 收款记录 | 收到的每笔钱:日期、客户、金额、方式 | 收款凭证 |
| 应收对账 | 自动汇出各客户欠款,月底对账单从这儿来 | 对账单 |
| 库存 | 进销自动加减,周小盘月大盘时核对 | 库存盘点表 |
| 月度汇总 | 当月卖了多少、赚了多少(示例数据)、哪个客户量大 | — |

### 2. 每天怎么用:下午固定30分钟

流程一点不变,只是**下午回收回执核对之后,多一步"录电脑"**:

1. 照着回收的对账联,把当天回执逐张录进"送货回执登记"(熟练后每张十几秒);
2. 当天收的钱录进"收款记录";
3. 采购小票录进"采购记录";
4. 完事看一眼"应收对账",谁家欠款蹿高了心里有数。

**谁来录?** 建议老板娘,正好和登记销售账是同一件事——录了Excel,纸质销售账可以慢慢退役,纸质回执单继续留着当凭证。

### 3. 没电脑怎么办

手机就够:用**WPS Office或腾讯文档**打开这个xlsx,手机平板电脑多端同步,老板在外面收款也能随时翻某家的欠款。建议把文件放到腾讯文档或WPS云文档里,老板和老板娘共用一份,谁改了对方都能看见——但**同一时间只让一个人录**,免得互相覆盖。

### 4. 这一步的甜头

- 月底出对账单:在"应收对账"里筛出某客户当月各笔回执,抄成对账单,原来2小时的活儿20分钟干完;
- 客户来电"我上月到底拿了多少货",当场手机查、当场报,客户觉得你专业;
- 月度汇总让你第一次看清:哪些货走量、哪些客户在缩量——该上门维护了。

## 四、阶段三(第4-6个月,每年几百到一两千元):上一款轻量进销存

Excel的天花板:数据多了卡、两个人不能同时录、开单还得手写再补录。到了这一步,才值得花钱买软件——市面上有一大类**面向批发配送、送货上门生意的进销存App**(应用商店搜"进销存""送货单""批发配送开单"就有一堆),年费大多几百到一两千元(示例)。咱不点名吹某一家,给你一把尺子自己量。

### 1. 选型五个硬指标

| 指标 | 具体要求 | 为什么 |
|---|---|---|
| 手机开单 | 配送员手机上几下点出送货单,不用电脑 | 咱的主力工具就是手机 |
| 蓝牙小票打印 | 配蓝牙便携打印机,现场打印送货单让客户签字 | 替代手写三联,但签字这道关不能省 |
| 客户对账单导出 | 一键导出某客户某期间对账单(图片或PDF),微信直接发 | 月底对账是咱最重的活儿 |
| 多人协同 | 老板、老板娘、配送员各有账号,权限能分开(配送员只能开单看不到进价) | 一家人一起干活 |
| 导入Excel历史数据 | 能把商品目录、客户档案、期初欠款、期初库存从Excel导进去 | 阶段二的家底不能丢 |

### 2. 试用评估清单(先试再买)

正经软件都有7-30天免费试用。试用期拿真单子跑,逐条打勾:

- [ ] 拿10个真实客户、30个常卖商品导进去,名字规格对不对?
- [ ] 早上照常接单,用它开一天的单,比手写慢还是快?
- [ ] 打一张蓝牙小票给相熟客户签,客户认不认这个格式?
- [ ] 导出一份对账单发给自己看,字段全不全(对账期间/期初欠款/明细/已收/期末应收)?
- [ ] 配送员账号能不能屏蔽进价和毛利?
- [ ] 数据能不能随时**导出成Excel**?——这条最重要,不能导出的软件等于把账本锁人家柜子里,坚决不用;
- [ ] 断网了能不能先开单、联网再同步?县城里信号不好是常事;
- [ ] 客服是真人吗?打个电话试试响应速度。

打勾超过6条再掏钱,先买一年,别一冲动买三年。上线后**头一个月Excel和软件并行录**,月底两边数字对得上,再让Excel退居备份。

## 五、升级信号:什么时候该往上迈一阶

别按日历升级,按"疼不疼"升级。出现下面信号(数字均为示例)说明现阶段撑不住了:

| 该从哪升到哪 | 升级信号(出现两条以上就动手) |
|---|---|
| 阶段一 → 阶段二 | 客户超50家;日单超15单;月底对账翻单子翻2小时以上;老板娘抱怨"谁欠多少钱越来越记不清" |
| 阶段二 → 阶段三 | 客户超80家;日单超20单;每天录单超40分钟;两个人抢着录一个文件;配送路上频繁要现场开单打单;A类客户点名要正规打印对账单 |

反过来说:客户三五十家、日单十来单,阶段二就够用,**别急着交年费**——省下的钱多印几本回执单更实在。

## 六、备份习惯:数据是身家,一周一备份

不管在哪个阶段,记住一句话:**账丢了比货丢了还疼**。

- **每周日晚上日结后**,把管理账本.xlsx 发一份到自己微信的"文件传输助手",文件名带日期,如"管理账本-备份20260731.xlsx";再存一份到网盘(百度网盘/WPS云/腾讯微云均可),双保险;
- 上了阶段三的软件后,**每月底导出一次全量Excel**(商品、客户、单据、应收),同样发文件传输助手+网盘——哪天不想续费了,拎着Excel就能换家软件或退回阶段二,主动权永远在自己手里;
- 纸质回执单存根联照旧装订保存(见《04-配送与回执》),电子账再全,签字的纸才是打官司认的凭证;
- 手机设锁屏密码,账本文件别外传,毛利数据是咱的底牌。

## 落地清单(本周就能做)

1. 对照第二节自查:微信好友备注是否已全部改成「级别-店名-老板称呼」,没改完的本周改完;
2. 去打印店按 templates/print/ 的版式印20本三联回执单(示例:一两百元),纸质订货登记表打印一沓放在接单手机旁;
3. 手机装好WPS Office(或腾讯文档),把 tools/管理账本.xlsx 存进去打开,先读"使用说明"页;
4. 花一个晚上,把商品目录录30个常卖商品、客户档案先录10家A类客户;
5. 从明天起试运行:每天下午回收回执后,花30分钟把当天回执、收款录进账本,坚持一周;
6. 本周日晚上做第一次备份:账本发微信文件传输助手一份、存网盘一份,以后每周日雷打不动。
