# 02-订单管理

**这篇解决什么问题:** 客户用微信语音、文字、电话下单,口说无凭,听错、记错、漏单,送错货还得跑第二趟,月底对账扯皮没依据。这篇教你把"嘴上说的单"变成"纸上写的单",一单不漏、一字不差。

## 一、为什么订单必须落到纸上(或表上)

咱这生意,客户下单全靠一张嘴:微信发条语音"明天来两桶酱油",电话里喊一句"老样子再来一套"。你脑子记着,忙起来一岔就忘了;听成别的规格,送过去客户不认,货拉回来还伤感情;月底对账,客户说"我没要过这个",你拿不出凭据,只能吃哑巴亏。

所以定一条死规矩:**凡是订单,不管从哪来,必须当场记进"订货登记表",并给客户回一条文字确认。** 没进表的,不算单;没确认的,不发货。

订货登记表可以是一个本子,也可以是手机备忘录、微信文件传输助手里的表格,格式统一就行(模板见 templates 目录,字段在下文第四节)。谁接的单谁记,一般是老板接单老板记,老板娘接单老板娘记,记完互相能看到(建议共用一个表,或每晚汇总到一处)。

## 二、接单三渠道,各有各的规矩

### 1. 微信语音单:立刻听、边听边记、文字复述

- **立刻听**,别攒着。语音攒到晚上一起听,最容易漏。
- **边听边记**:听一句记一句,记到订货登记表(或先记草稿)。
- 听不清、有歧义的,**马上追问**:"哥,您说的一件醋是宁化府420ml那个吗?"
- **背景太吵听不清怎么办**(饭店后厨炒菜声、抽油烟机声大是常事):
  - 先长按语音点"转文字",微信自带,能看个大概——但方言、品名转出来常是错的,**转出来的字只能当参考,拿不准的必须问**;
  - 反复听两遍还不行,别硬猜,回一句固定话术:"哥,您那边有点吵,怕给您送错,麻烦打几个字,或者过会儿再说一遍?"客户一般都配合——他也怕收错货;
  - 还不行就直接打个电话过去问。**宁可多问一句,不能猜着发货**:猜错一单,退货跑一趟,比问那一句贵十倍。
- 记完**必须回一条格式化文字**让客户确认(见第三节"复述确认"铁律)。

### 2. 微信文字单:复制进表,照样确认

客户发文字最省事,但别以为文字就不会错——客户自己也会写错、写含糊("来点花椒"是来几袋?)。做法:

- 把客户的文字**复制进订货登记表**,补齐规格、数量、单价。
- 有含糊的当场问清。
- 同样回一条复述确认,把补齐后的完整单发回去。

### 3. 电话单:挂电话前复述一遍

电话最危险,一句没听清就过去了,还没有记录。做法:

- 接电话时手边永远放着本子和笔(或开着手机备忘录),**边听边记**。
- **挂电话前,对着记录复述一遍**:"我给您念一遍啊:金龙鱼酱油10L两桶、宁化府陈醋420ml一件15瓶,明早10点前送到,对吧?"客户说"对",才挂电话。
- 挂完电话,马上把内容誊进订货登记表,**再补发一条微信文字确认**(客户有微信的话)。电话说的话留不下来,微信文字留得下来。

## 三、"复述确认"铁律:每单必回一条格式化文字

这是订单管理的命根子,一单都不能省。客户怎么说是他的事,**门店回过去的那条文字,才是双方认账的依据。**

看一个示例对话:

> **客户(语音):** "喂,明天来两桶酱油一件醋啊。"
>
> **门店(文字回复):** "收到:金龙鱼酱油10L×2桶、宁化府陈醋420ml×1件(15瓶),明早10点前送到,对不对?"
>
> **客户:** "对。"

就这么简单。这条回复里有四样东西缺一不可:

| 要素 | 例子 | 为什么必须有 |
|---|---|---|
| 品牌+品名 | 金龙鱼酱油 | 酱油有七八种,不写品牌必错 |
| 规格 | 10L、420ml×15瓶 | "一桶""一件"最容易扯皮 |
| 数量+单位 | 2桶、1件 | 数字写清,别用"两三桶" |
| 送达时间 | 明早10点前 | 饭店赶着中午开火,晚了误事 |

客户回"对"或者不回但也没提异议,这单就算确认了。客户如果说"不对,是海天的",马上改表、再发一遍确认。**改单也走同样流程:以最后一条确认文字为准。**

送货时,这条确认就变成《送货回执单》上的明细,客户签了字,证据链就全了——微信确认 → 回执单签收 → 月底对账单,三步一环扣一环(见《04-配送与回执》《05-财务与对账》)。

## 四、常见坑:口语规格歧义,用"客户常用品对照表"治

三线小城的饭店老板说话都省事:"一件醋""一桶油""老样子来一套"。坑就坑在这儿:

- "一件"到底是几瓶?醋有一件12瓶的、15瓶的、20瓶的,厂家不同装箱数不同。
- "一桶酱油"是10L的餐饮桶,还是1.9L的家用桶?
- "老样子"是上周的老样子,还是上个月的老样子?

**解决办法:给每个老客户建一张"客户常用品对照表",记在客户档案卡上**(客户档案卡见《01-业务模式与客户管理》)。格式示例:

| 客户 | 客户口头说法 | 实际品项 | 规格 | 换算 |
|---|---|---|---|---|
| 老王面馆 | "一件醋" | 宁化府陈醋 | 420ml | 1件=15瓶 |
| 老王面馆 | "一桶酱油" | 金龙鱼酿造酱油 | 10L | 1桶=10L |
| 老王面馆 | "一袋盐" | 加碘精制盐 | 400g×50包 | 1袋=1整袋50包 |
| 红星烧烤 | "一件孜然" | 散装孜然粒 | 500g/袋 | 1件=10袋 |
| 红星烧烤 | "老样子一套" | 孜然2袋+辣椒面2袋+蚝油1瓶 | 见档案卡 | 固定组合 |

*(以上均为示例)*

用法:客户语音一来,先查他的对照表,按表翻译成标准品规格,再复述确认。新客户头三次下单,**每一项都要问清规格**,问清一项记一项,三次下来对照表就建起来了。客户换了牌子、换了规格,当场更新对照表。

这张表还有个好处:配送员、老板娘谁接单都能接,不用"只有老板听得懂王老板说啥"。

## 五、订货登记表:什么时候记、谁记、状态怎么走

### 字段

日期 / 订单号 / 客户 / 品名 / 规格 / 数量 / 单位 / 单价 / 金额 / 要求送达时间 / 备注 / 状态

订单号规则:**DD+年月日+2位序号**,如 DD20260731-01、DD20260731-02,当天从01往后排。一个客户当天的一次下单算一个订单号,一单多个品项就写多行、共用一个单号。

### 什么时候记、谁记

- **接到单当场记**,最晚不过10分钟。谁接的单谁记,记完在备注写上自己名字缩写也行。
- 客户下单高峰在前一天下午到当天清晨,晚上睡前和清晨5点各**通盘核一遍**:微信逐个聊天窗口翻一遍、电话回忆一遍,看有没有漏记的。清晨5:00-7:00 汇总订单、生成采购汇总单时,以订货登记表为唯一依据(见《03-采购管理》)。

### 状态流转

每行订单有个"状态"格,跟着货走:

**已接单 → 已配货 → 已送达 → 已签收**

- **已接单**:复述确认发出、客户认了,就是已接单。
- **已配货**:清晨分拣装车、上了装车配送单,改成已配货。
- **已送达**:配送员送到客户店里,改成已送达。
- **已送达后客户在回执单上签了字**,下午回收回执核对时改成**已签收**,同时登记销售账、应收账。

每晚日结时扫一眼登记表:**只要还有不是"已签收"的单,必须查清楚**——是没送到?回执没收回来?还是漏了?状态表就是防漏单的最后一道闸。

## 六、截单时间制度:晚9点截次日单

没有截单时间,清晨采购单就定不下来,天天被加单追着跑。定一条并告诉所有客户:

> **每晚9点前下的单,次日上午送到;9点以后的单,算后天的,或按紧急加单处理。**

新客户建档时就说清,老客户用一条群发或朋友圈通知:"各位老板,为保证第二天按时送货,请每天晚上9点前把次日要的货发给我,9点后的单尽力安排但不保证哈。"

**客户半夜、凌晨发的单怎么办**:饭店老板收完摊常常十一二点甚至凌晨一两点才发单,这很正常,**不用爬起来回**。规矩是:

1. 清晨5点核单时(见第五节)统一转录、统一发复述确认——凌晨发的单,只要在你清晨核单前发的,都算当天的单,照送;
2. 清晨发的确认,客户多半还在睡、没回"对"怎么办?**老客户**按他的常用品对照表照常备货装车,送到店里当面再念一遍确认;**新客户或金额大、规格拿不准的单**,必须等客户回复了才装车,联系不上就先不送,别猜;
3. 跟客户把话说在前头:"您几点发单都行,我早上5点统一看,给您回条确认,您醒了瞅一眼就行。"客户知道你有这个规律,就不会怪你半夜不回。

**紧急加单怎么处理**(9点后甚至当天早上才来的单):

1. 先看库存:门店有现货的,能捎就捎——顺路捎带,不单独跑。
2. 库存没有的:如实告诉客户"这个今早市场买不上了/来不及了,明天一早给您送",别硬答应。
3. 确实救急的(饭店中午等米下锅):单独跑一趟可以,但要跟客户说明这是特事特办,常干不行——次数多了客户就没规矩了。
4. 紧急加单**照样进订货登记表、照样复述确认**,备注栏写"加急",别因为急就跳过流程——越急越容易错。

## 七、预订单与周期性订单:食堂的固定单要"主动管"

大学食堂档口、单位食堂这类A类客户,常常是每周固定要货:每周一、四各来一次,品项八九不离十。这种单别等客户催,**门店主动管起来**:

- 在客户档案卡上记清:固定送货日、固定品项清单("标准单")。
- **提前一天下午主动发确认**:"张师傅,明天周四,按老规矩送:大豆油20L×4桶、酱油10L×3桶、味精1kg×2袋,有增减吗?"客户回"再加一件醋",改完再确认一遍。
- 客户确认后,照常编订单号、进订货登记表,备注写"周期单"。
- 寒暑假、节假日食堂停伙,提前问一句"下周还送吗",别白采购一堆。

预订单(客户提前几天定好某天要的货,比如饭店办酒席)也一样:接到就进表,日期写实际送货日,备注"预订单+下单日期",每天清晨汇总时按送货日期筛,到日子自动进当天的采购汇总单,不会忘。

## 八、落地清单(本周就能做)

1. **今天起执行"复述确认"铁律**:每一单回一条格式化文字(品牌+品名+规格+数量+送达时间),把示例话术抄在手机备忘录里照着发。
2. **打印或抄一份订货登记表**(见 templates 目录),放在接单的手机旁边,接一单记一单,单号从 DD+当天日期-01 开始编。
3. **挑10个下单最勤的老客户,建"客户常用品对照表"**:把他们常说的"一件""一桶""老样子"逐个问清、记到客户档案卡上,以后每周补几个客户。
4. **群发一条截单通知**:每晚9点截次日单,固定话术发给所有客户并发一条朋友圈。
5. **每晚日结时过一遍登记表状态**:凡是没走到"已签收"的单,当晚查清原因。
6. **给食堂等固定客户设"标准单"**:本周起,送货前一天下午主动发确认,别再等客户来电。
