# 对账单

**用途一句话:** 月末(或每周)把这段时间给客户送的每一单、收的每一笔钱列清楚,双方签字确认该欠多少,收款有据、账目不扯皮。(对账收款流程见《05-财务与对账》docs/05-财务与对账.md)

## 空白表格(可直接照着画到纸上或复印,一个客户一张)

**中山店铺 对账单**

期初欠款:________元

|  |  |  |

|  |  |  |

本期已收:________元

双方确认签字:门店(中山店铺)__________  客户__________  日期__________

## 填写说明

| 字段 | 怎么填 | 谁来填 | 什么时候填 |
| --- | --- | --- | --- |
| 对账期间 | 月结客户写整月(如7月1日至7月31日),周结客户写一周;和客户约定的结算周期一致 | 老板娘 | 期末做对账单时 |
| 客户 | 客户档案卡上的店名全名 | 老板娘 | 做单时 |
| 期初欠款 | 抄上一张对账单的"期末应收";第一次做对账单就写建账时确认的老欠款,没有写0 | 老板娘 | 做单时 |
| 本期送货明细(日期/回执单号/金额) | 把这个客户本期每一张回执单的对账联翻出来,按日期从早到晚一单一行抄,金额单位是元;最后加一行合计 | 老板娘 | 做单时,抄完和对账联总数核一遍 |
| 本期已收 | 本期实际收到这家的钱加总(现金+微信转账都算),和收款记录对上 | 老板娘填,老板核 | 做单时 |
| 期末应收 | 期初欠款+本期送货合计-本期已收,单位是元;这个数就是下期的"期初欠款" | 老板娘算,老板核 | 做单时 |
| 双方确认签字 | 门店签老板名字;客户核对无误后签字,最好按两份,一家一份;A类客户对完账当场约定付款日期 | 老板与客户 | 送对账单上门核对时 |

**提醒:** 客户对账时若说某单不对,别争,让他拿客户联出来和门店的对账联、存根联三头一对,当场就清楚——这也正是让客户离不开门店的地方。

## 示例填写(金额均为示例)

| 日期 | 回执单号 | 金额 |
| --- | --- | --- |
| 2026-07-31 | HZ20260731-01 | 216元 |

本期送货合计:216元  本期已收:800元  期末应收:216元(800+216-800)
