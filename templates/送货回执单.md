# 送货回执单

**用途一句话:** 货送到、客户签字,这张单就是门店收款的凭证,也是饭店老板核对进货、管住员工的工具——一单两头用。(为什么这张单是生意的灵魂,见《04-配送与回执》docs/04-配送与回执.md;对账用法见《05-财务与对账》docs/05-财务与对账.md)

## 空白表格(可直接照着画到纸上,建议去印刷店印成三联无碳复写单,一式三联)

**中山店铺 送货回执单**

单号:HZ____________  日期:__________

客户店名:______________________  地址:______________________

| 品名 | 规格 | 数量 | 单位 | 单价 | 金额 |
| --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |
|  |  |  |  |  |  |
|  |  |  |  |  |  |
|  |  |  |  |  |  |
|  |  |  |  |  |  |

合计(大写):____________________  合计(小写):________元

送货人签字:__________  收货人签字:__________  收货时间:____月____日____时____分

联次说明:一式三联——①客户联(留给客户,老板凭此核对进货、月底对账)②对账联(门店带回,登应收账、月底做对账单的依据)③存根联(门店按单号顺序留存备查)

> 底注(印在单子最下方):请收货人核对品名数量后签字;单价金额供店主对账使用。

## 填写说明

| 字段 | 怎么填 | 谁来填 | 什么时候填 |
| --- | --- | --- | --- |
| 单号 | "HZ+年月日+2位序号",如 HZ20260731-01,当天从01往后排,和装车配送单上的号一致 | 老板 | 上午装车前开单时 |
| 日期 | 送货当天日期 | 老板 | 开单时 |
| 客户店名 | 客户档案卡上的店名全名 | 老板 | 开单时 |
| 地址 | 抄客户档案卡的店铺地址 | 老板 | 开单时 |
| 明细行(品名/规格/数量/单位/单价/金额) | 照订货登记表抄,一行一个品,单价金额单位是元;字写清楚,客户老板要拿这个逐项核对 | 老板 | 开单时,禁止到了客户店里再现写 |
| 合计(大写+小写) | 小写写数字,大写用"壹贰叁肆伍陆柒捌玖拾佰仟"防涂改,两处必须一致 | 老板 | 开单时 |
| 送货人签字 | 配送员送到后签自己名字 | 配送员 | 交货时 |
| 收货人签字 | 客户老板签;老板不在,由档案卡上的"指定收货人"签,并让他当面清点品名数量 | 客户方 | 交货时 |
| 收货时间 | 签字时写上当时的月日时分,有争议时说得清 | 配送员 | 交货时 |

**提醒:** 跟客户老板讲清楚这张单的好处——他不在店里时员工代收货,单上品名/规格/数量/单价/金额一目了然,月底拿客户联和门店对账单逐单核对,员工虚报冒领没空子钻。这是门店帮他管店的服务,也是他一直找门店订货的理由。
